if oder else?if prüft eine Bedingung. else if prüft eine weitere. else gilt, wenn die vorherigen Bedingungen falsch waren.
mousePressed oder mousePressed()?mousePressed ist true / false. Die Funktion void mousePressed() läuft bei jedem neuen Mausklick.
Hinweis zum SprachumfangDiese eigenständige Lernumgebung führt eine Auswahl der Processing-Java-Syntax aus. Für vollständiges Processing (z. B. P3D, Bibliotheken und Klassen) ist die offizielle Processing-IDE nötig.

Übung zum Selbermachen

Lade das Beispiel „if / else: Farbe bei Mausklick“. Ändere es so, dass der Kreis grün wird, solange die Maustaste gedrückt ist, und ansonsten gelb bleibt. Ergänze danach eine else if-Bedingung, die von der Mausposition abhängt.
