ETAPPE 2 · STRUKTUR SEHEN

Gleichungen angleichen

Nun wird das Argument so umgeformt, dass Verschiebung und Faktor getrennt ablesbar werden.

Normalform zum Ablesen
g(x) = a · f(b · (x − d)) + e
aStreckung/Stauchung in y‑Richtung mit Faktor |a|: |a| > 1 Streckung, 0 < |a| < 1 Stauchung; bei a < 0 zusätzlich Spiegelung an der x‑Achse
bStreckung/Stauchung in x‑Richtung mit Faktor 1/|b|: |b| > 1 Stauchung, 0 < |b| < 1 Streckung; bei b < 0 zusätzlich Spiegelung an der y‑Achse
drechts bei d > 0, links bei d < 0
eoben bei e > 0, unten bei e < 0

Parameter-Lupe

Lies a, b, d und e aus der bereits angeglichenen Form ab.

a bewirkt eine Streckung/Stauchung in y‑Richtung mit Faktor |a|: |a| > 1 Streckung, 0 < |a| < 1 Stauchung. Bei a < 0 kommt die Spiegelung an der x‑Achse hinzu.
b bewirkt eine Streckung/Stauchung in x‑Richtung mit Faktor 1/|b|: |b| > 1 Stauchung, 0 < |b| < 1 Streckung. Bei b < 0 kommt die Spiegelung an der y‑Achse hinzu.
d verschiebt nach rechts bei d > 0 und nach links bei d < 0.
e verschiebt nach oben bei e > 0 und nach unten bei e < 0.
